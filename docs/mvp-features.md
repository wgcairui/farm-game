# MVP 功能清单（Phase 1）

目标：**4-6 周**做出能玩的单机版，验证种菜核心循环。

## 必须完成（Must Have）

### F1. 农场主场景
- [ ] 6×6 地块网格（36 块地），点击地块可种植
- [ ] 地块有 3 种状态：空地 / 已种植 / 可收获
- [ ] 已种植地块显示作物图标 + 生长进度条
- [ ] 摄像机可拖动缩放（适配刘海屏）

### F2. 作物系统
- [ ] 至少 **5 种作物**（白萝卜、土豆、玉米、番茄、草莓）
- [ ] 每种作物：种子 id、名称、图标、生长时长（30s ~ 4h）、售价、种子价
- [ ] 生长状态机：`种子 → 发芽 → 幼苗 → 成熟 → 枯萎`
- [ ] 枯萎作物可一键清理
- [ ] 多地块并行生长，独立计时

### F3. 商店系统
- [ ] 种子商店面板，显示可购买作物列表
- [ ] 金币足够时点击购买，金币不够弹提示
- [ ] 购买后种子进入背包
- [ ] 关闭面板不消耗金币

### F4. 背包/仓库
- [ ] 显示当前拥有的种子数量、作物数量
- [ ] 收获时作物进入仓库（仓库容量初始 50，上限可扩）

### F5. 经济系统
- [ ] 金币货币，初始 200
- [ ] 卖作物获得金币（成熟作物售价）
- [ ] 仓库一键出售所有成熟作物

### F6. 存档/读档
- [ ] 玩家数据持久化（`PlayerPrefs` 或 `localStorage`）
- [ ] 退出再进入，地块状态恢复
- [ ] **关键：用时间戳记录种植时刻，不存当前状态**
- [ ] 离线收益结算：作物在玩家离线期间成熟，自动入仓库

### F7. 基础 UI
- [ ] 顶部资源栏（金币 / 钻石 / 仓库容量）
- [ ] 底部 Tab：农场 / 商店 / 仓库 / 设置
- [ ] 简单新手引导（强制引导第一颗种子种下）

## 不做（Out of Scope，Phase 2+ 再加）

- ❌ 好友系统 / 偷菜（Phase 2）
- ❌ 排行榜（Phase 2）
- ❌ 土地升级 / 解锁新地块（Phase 2）
- ❌ 动物养殖（Phase 3）
- ❌ 装饰系统（Phase 3）
- ❌ 任务系统（Phase 3）
- ❌ 道具（化肥/加速卡）（Phase 2）
- ❌ 加工系统（Phase 3）
- ❌ 推送通知（Phase 3）

## 验收标准

✅ 玩家可以：买种子 → 选地块种植 → 等待生长 → 收获 → 卖出获得金币 → 用金币买更贵的种子

✅ 关闭游戏 1 小时后重开，离线期间成熟的作物自动入仓库

✅ 玩家在 10 分钟内能搞清楚怎么玩（不需要看教程）

| 项目 | 数量 |
