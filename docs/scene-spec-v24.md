## 1. 画布、投影与适配

- 逻辑画布：`692 × 1218`。
- 世界投影：**2:1 dimetric**，轴角约 `26.565°`，不使用“45°真等距”的错误表述。
- HTML 预览：`width:min(100vw,692px)`，`aspect-ratio:692/1218`，保持场景等比缩放。
- 已验证宽度：`375px`、`390px`、`430px`、`692px`；无横向溢出，页面高度误差小于 1px。
- 窄屏最小文字约 `7.5–8.6 CSS px`。这是完整场景缩略显示的结果；高像素密度只能改善清晰度，不能解决字号过小。正式游戏必须对关键提示采用独立 HUD 字号策略，并在实际屏幕尺寸上复核可读性。

## 2. 地块几何

```text
床顶点 T0 = (393, 589)
U = (47, +24)
V = (-47, +24)
网格 = 4 × 6 = 24 格
瓦片外接盒 = 94 × 48
```

第 `(i,j)` 格中心：

```text
C(i,j) = (393 + 47(i-j), 613 + 24(i+j))
```

- `j <= 1`：8 格已耕土壤和幼苗。
- `j >= 2`：16 格未耕草地。
- 相邻格中心距严格等于 `U` 或 `V`，因此是边与边连续的格网，不是角对角接触。
- 顶面缩放 `0.88` 只控制榃色缝隙宽度，不改变拓扑。

## 6. 交互命中层

SVG 负责视觉，HTML `.hit-layer` 负责语义和命中区域。当前包含 13 个按钮：分享、音乐、菜单、商城、公益、一键务农、任务、关闭好友求助，以及 5 个底部导航。

规则：

- 每个命中区最小 `44 × 44 CSS px`。
- 命中区可大于可见图标，但不能互相重叠或越出屏幕。
- 375px 实测：无小于 44px 的目标、无目标重叠、无目标越界。
- 关闭按钮靠右吸附，避免以视觉圆点为中心时命中区超出屏幕。
- 键盘聚焦时显示浅黄色焦点环；平时命中层完全透明。

Cocos Creator 中应复用这一原则：视觉 Sprite 与 `UITransform`/Button 点击节点分离，不要直接把缩放后的 Sprite 尺寸当点击范围。

## 8. 纹理规则

草地和土壤颗粒必须使用真实 multiply 合成：

```xml
<feTurbulence ... result="n"/>
<feColorMatrix in="n" type="saturate" values="0" result="g"/>
<feComponentTransfer in="g" result="gc">...</feComponentTransfer>
<feComposite in="gc" in2="SourceGraphic" operator="in" result="clip"/>
<feBlend in="SourceGraphic" in2="clip" mode="multiply"/>
```

禁止使用白色矩形叠滤镜；那会整体抬高亮度和蓝通道，造成草地发灰。

正确合成不等于材质达标：复审发现地块像软垫、花石板像贴纸、茅草/树冠/篮子重复几何明显。V07–V09 优先修轮廓、明暗和材质组织，不靠均匀增加颗粒或统一缩小所有元素代替。

## 11. Cocos Creator 映射

- 场景层使用独立 Sprite/Node，按本规范图层顺序设置 sibling index。
- 草地必须位于树林之前；UI Canvas 位于所有场景节点之后。
- 地块位置用 `C(i,j)` 计算，不手摆。
- 作物按屏幕 y 值排序，保证前后遮挡。
- 主页逻辑设计坐标统一为 `692×1218`，安全区与设备纵横比单独适配，不混用 `750×1334` 或非等比拉伸。坐标原点转换及屏幕等效命中尺寸见 [Cocos 集成指南](./cocos-integration.md)。
- 所有可点 Sprite 配独立 Button 节点，窄屏最小命中区对应 44 CSS px。
