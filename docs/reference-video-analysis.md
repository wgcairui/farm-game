## 二、镜头与图层结构（为什么需要扩图）

竞品验证了核心结论：**主界面不是一屏图，而是一张大地图 + 可漫游镜头 + 屏幕固定 UI**。

- 地图底图（含远景、地表、道路、水系、装饰）尺寸大于屏幕，四向均可拖动；
- 天空/远山带轻微视差（滚动时位移慢于地表）；
- 地块、建筑、作物是地图上的对象节点，随地图一起滚动；
- HUD、左右功能列、底部导航、任务条固定在屏幕层，不随地图移动。

因此生成底图时：中央留出 24 格连续地块区（占位即可，作物/地块由引擎叠加），四周要按"镜头会滚到这里"的标准做成完整可看的场景，不能是虚化或截断的边缘。之前多轮"扩图/拉远"生成失败的根本原因也在此：目标不是单屏海报，而是**一张可漫游的大图**。

### 建议画布规格

- 设计基准：屏幕 720×1280（与现有 v24 一致）；
- 地图底图：≥ 2 屏宽 × 2 屏高（即 ≥1440×2560），推荐 2160×3840（3x）留漫游余量；
- 24 格地块区置于地图中心偏下，占位面积按"每格约屏宽 1/7"预留；
- 四周安全区：UI 固定在屏幕层，地图四周不需要留 UI 空区，但需要完整场景内容。

## 三、图层分解（自底向上共 12 层，4 个组）

```
┌─ 屏幕组（不随地图滚动）──────────────┐
│ L12 弹窗层        等级提升/商店/仓库/任务奖励      │
│ L11 UI 层         HUD、功能列、任务条、底部导航     │
├─ 对象组（随地图滚动，按 y 排序）────────┤
│ L10 特效层        收获星星、浇水水花、种植尘土      │
│ L9  作物层        每格作物精灵（4 阶段 + 成熟态）    │
│ L8  地块层        24 格底座（锁定/草地/耕地/湿土）   │
│ L7  建筑层        农舍、狗窝、木牌、栅栏、水井       │
├─ 地图组（随地图滚动，含视差）────────────┤
│ L6  水域层        池塘水面（可动画）、荷叶、小桥     │
│ L5  道路层        石板路/土路（拼块）              │
│ L4  地表层        草地大底图（无缝平铺或整图）       │
│ L3  中景层        树林带、灌木丛、丘陵             │
│ L2  远景层        远山 2 层（视差滚动）            │
│ L1  天空层        天空渐变 + 云朵（最慢视差）        │
└───────────────────────────────────┘
```

排序规则：对象组内按世界坐标 y 值动态排序（角色/建筑/树可互相遮挡）；地图组在对象组之下；屏幕组永远在最上。

### 风险提示

- 大地图底图（批次 A）是最大不确定性：模型对"中央留空 + 四周完整"的服从度有限，准备两套方案——多候选直出，或以 v1 为中心按镜像/延展拼接后对四角做局部重绘兜底。
- 特效帧（批次 C）对帧间一致性要求高，若单帧独立生成不连贯，改为整条帧表一次生成再切分。
- 水面 2 帧（批次 F）同理：同一提示词仅改"水面波纹位置"重生成，构图偏移即弃。
