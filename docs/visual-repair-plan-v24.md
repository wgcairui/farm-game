## 2. 问题与实施任务

优先级高：影响空间、核心土地或主要轮廓；中：影响材质、识别和层级；低：收尾精修。下列任务状态全部为“待实施”，建议不是已经验证的新坐标。

| 编号 | 优先级 | 实际画面依据 | 修正动作 | 验收条件 |
|---|---|---|---|---|
| V01 | 高 | 左下栅栏横栏跨过绿色地块顶面 | 移到左前侧外缘，沿边界排布，保留草地间隔 | 横栏不跨可种植顶面；柱脚落地；不靠缩小土地解决 |
| V02 | 高 | 草屋、狗屋近正面，土地为斜俯视 | 重画屋顶、可见侧墙、屋檐厚度与落地阴影 | 建筑与土地共享俯视程度和空间方向，不像正面贴纸 |
| V03 | 高 | 树林连续成墙，中央无远处草坡通道 | 打开中央林带，远层降对比，保留少数近景主树 | 能分辨远山、远林、草坡、近景建筑，不再用等清晰树冠填满背景 |
| V04 | 高 | 时间胶囊横压草屋右侧屋檐与墙面 | 联动重排公益、篮子、时间并减轻底板重量 | 时间不切断建筑主要轮廓，功能列之间有清楚间隔 |
| V05 | 高 | 篮子左侧灰色横条矩形悬空、归属不明 | 先确认语义；若为烟囱则接入屋顶并表现体积，若无功能则移除 | 不存在孤立占位面板；记录物件的场景/HUD 归属 |
| V06 | 中 | 商城细长似小塔，公益过重、手掌难辨 | 强化雨棚和门面横向体量，重画掌心剪影，统一标签重量 | 无文字辅助也能辨识商铺和托手；不是整体等比放大 |
| V07 | 中 | 大白花、黄花和椭圆石板像贴纸 | 花改为疏密有别的小簇；石板改变形状、角度及草地嵌入关系 | 装饰不抢土地与建筑；土地外围留安静区域 |
| V08 | 中 | 地块厚边、重复内圈高光像坐垫 | 保留网格，减少重复描边，增加不规则草皮边与接触阴影 | 草地和土壤材质可区分；不改变连续邻接关系 |
| V09 | 中 | 屋顶直线、圆树冠、篮横条规则重复 | 茅草成束、树冠成团、编织跟随曲面 | 体积由轮廓和明暗成立，不用均匀增加颗粒代替材质 |
| V10 | 中 | 手套悬在任务与宠物之间，目标不明 | 普通状态隐藏；引导状态明确指向具体目标 | 普通主页无常驻手套；引导不误指宠物、不截获无关触摸 |
| V11 | 中 | 仓库袋子、装扮彩条、好友小鸟语义偏弱 | 强化储物、服饰、信件/社交的识别线索 | 遮住文字复核功能语义；保留已合理的导航尺寸 |
| V12 | 低 | 最底部深绿色宽波带像网页页脚 | 用低对比草丛与局部阴影柔化过渡 | 收尾融入草地，不增加 ID/version 或密集装饰 |

## 3. 实施顺序与交付关卡

### A. 空间结构修正（V01–V05）

- 从 `gen_v24.py` 建立后续候选版本，保留 v24 图像作为复审基线，不覆盖后冒充原版证据。
- 栅栏、建筑、树林、右侧功能区先做整体构图；其中 V02 建筑轮廓与 V04/V05 必须联合确定。
- 交付候选全图及上述区域局部图，与参考图并排检查。
- 关卡：所有高优先级项有画面证据确认关闭，才能冻结相应布局。

### B. 材质、图标与收尾（V06–V12）

- 先统一明暗、描边、材质和标签规范，再处理花石板等小装饰。
- V08 只能改地块表现，不重新推导或移动已成立的连续网格。
- V10 交付普通/引导两个状态；V11 做遮文字识别复核。
- 关卡：完整画面无新增遮挡，图标语义清楚；不以相似度分数抵消视觉缺陷。

### C. 工程回归与视觉复验

- 为候选版本同步更新 `LAYOUT`、允许重叠列表、装饰保留区、视觉节点和命中区，不能只改坐标表而不改画面。
- 单独检测栅栏与土地顶面、时间与建筑主要轮廓；现有道具/道具豁免及时间/草屋白名单不能作为放行理由。涉及精确多边形的检查属于后续待新增功能，不声称现有审计已具备。
- 执行候选生成器的 XML/引用/布局审计，再用实际浏览器验证 692/375/390/430px。
- 各宽度记录完整画面、文字可读性、无横向溢出、每个操作目标至少 44×44 CSS 屏幕像素、无命中区重叠/越界，以及普通/引导状态。
- 高 DPI 只能改善清晰度，不能解决字号过小。关键 HUD 需独立字号与长文本测试。
- 交付复验表：问题编号、修复版本、截图路径、复验结论、剩余问题。只有实际观察过的项目可以标完成。

### D. 资源冻结与 Cocos 接入

- A–C 通过后才能冻结正式美术；可在此前并行做灰盒、存档与种植流程，不把占位素材视为最终资源。
- 按独立场景对象、地块、作物、HUD 导出资源，记录来源、尺寸、锚点、落地点、图层、倍率及版本；不能把整张参考截图或整页 UI 当成游戏底图。
- 具体导入、坐标映射、安全区、命中层和客户端验证见 [Cocos 集成指南](./cocos-integration.md)。
- 正式客户端必须重新验收，网页静态渲染和触控区记录不能替代 Cocos 实机验证。
